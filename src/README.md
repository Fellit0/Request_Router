# Назначение программы
Программа предназначена для команды поддержки, читающая обращения из JSON и CSV, определяющая категорию и приоритет по заданным правилам, сохраняющая результат и сообщающая об ошибках

# Требования к окружению
Интерпретатор Python 3 версии и выше, стандартные библиотеки


# Входные форматы
JSON - поля (идентификатор обращения) и text (текст обращения) в формате объекта
CSV - данные id (идентификатор обращения) и text (текст обращения) разделены запятой в формате таблицы


# Поля результата
записи содержат следующие поля:

id - уникальный идентификатор записи
category - категория (access, billing, bug, other) вычисляемая по первому встретившемуся ключевому слову из списка
priority - уровень приоритета обрабатываемости запроса (high, medium, low), высчитываемый по маркерам из категории

# Пример логики работы
Запись с id: r-001 содержит текст со словами войти и пароля. 
1. По справочнику ключевых слов первое совпадение определяет категорию как access.
2. Специальных признаков высокой критичности (high) в тексте запроса не обнаружено. 
3. Согласно правилам для категории access, базовым или промежуточным уровнем в данном случае становится приоритет medium.
В результате в выходном файле для записи `r-001` будут сохранены именно эти вычисленные значения.

# Вызов справки
Команда выводит описание программы, назначение аргументов `--input` и `--output`, после чего успешно завершается с кодом `0`:

python3 src/main.py --help

# Обработка JSON-файла и сохранение результата
Команда считывает JSON-массив данных, выполняет очистку и нормализацию, рассчитывает поля и сохраняет итоговый JSON-массив по указанному пути:

python3 src/main.py --input datasets/requests.json --output src/result.json

# Обработка входящего CSV-файла и сохранение результата
Аналогичный запуск программы для табличных данных. На выходе формируется точно такой же по структуре и типам данных JSON-файл:

python3 src/main.py --input datasets/requests.csv --output src/result.json
